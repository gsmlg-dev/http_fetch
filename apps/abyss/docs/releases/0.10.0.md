# Abyss 0.10.0

QUIC applications can set `quic_options: [idle_timeout: :infinity]` and issue
explicit keepalive requests through `Abyss.QUIC.ping/2`. Install `elixir_quic`
0.21.17 or newer explicitly to use these engine capabilities. The core package
continues to build and run ordinary UDP services without a QUIC engine or Rust.

Disabling the local idle timeout advertises a zero `max_idle_timeout` transport
parameter. A peer's finite idle timeout still constrains the negotiated lifetime,
including the engine's minimum of three probe timeouts. It does not override peer
policy or guarantee that an intermediary keeps a network path alive. Zero is not
a valid local `idle_timeout` option; use `:infinity` to disable it.

Keepalive is caller-managed. `Abyss.QUIC.ping/2` provides an explicit bounded
operation; it does not install an automatic cadence. Handshake, callback, closing
and draining deadlines retain their independent finite bounds.

Both `abyss` and `abyss_raw` are released at `0.10.0` under one shared tag and
GitHub Release. Install `{:abyss, "~> 0.10.0"}` for core and explicitly add
`{:abyss_raw, "~> 0.10.0"}` for native DHCP/ARP sockets. The raw package's
implementation and compatibility facade remain unchanged.

The coordinated release workflow verifies both archives against the selected
commit, publishes both packages and documentation sets, and requires fresh exact
Hex consumers, matching registry/archive checksums, and isolated DHCP/ARP wire
traffic before marking publication complete.
