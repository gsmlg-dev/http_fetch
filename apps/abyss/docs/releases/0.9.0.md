# Abyss 0.9.0

The optional native package is now `abyss_raw`, released together with core at
version `0.9.0`. Explicitly add `{:abyss_raw, "~> 0.9.0"}` for interface-bound
DHCP client sockets and raw ARP. Ordinary core consumers retain their Rust-free
build and runtime boundary.

`Abyss.DhcpSocket.Native` retains all five operations, owner messages and native
resource behavior. The implementation name `AbyssDhcpSocket.Native` is retained
so the released core `0.8.1` facade also works with the new add-on. Native artifacts
now belong to `:abyss_raw`. A missing add-on is reported as
`{:error, {:missing_optional_dependency, :abyss_raw}}`; failed native loads retain
`{:error, {:optional_dependency_load_failed, :abyss_raw, reason}}` and operation
errors remain unchanged.

The coordinated workflow requires committed shared versions, builds both
archives at one selected source commit, creates one immutable tag and GitHub
Release, and publishes both packages and docs. Retry verifies any existing
publication against the intended artifacts before uploading missing packages.
Completion requires fresh Hex consumers and checksum verification of both.

No new packet protocols or changes to the OTP socket backend are included.
