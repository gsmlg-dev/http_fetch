# Security Policy

## Supported Versions

Hell's initial release version is `0.1.0`. The fork maintainers are responsible
for documenting the supported-release policy.

## Reporting a Vulnerability

As of 2026-10-14, GitHub private vulnerability reporting is disabled for
[gsmlg-dev/hell](https://github.com/gsmlg-dev/hell/security/advisories), and no
confirmed private contact is documented here. Maintainers are responsible for
establishing and documenting a private reporting channel. Do not post vulnerability
details in public issues. The upstream project's reporting contact is not a Hell contact;
Hell reports should not be sent to upstream maintainers.
