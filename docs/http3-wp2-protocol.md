# WP2: bounded HTTP/3 companion profile

Implementation worktree: `.trees/http3-completion`, branch
`codex/http3-completion`. Baseline: `ddcc053311d311c18e014e635a57a75cd0313041`.
Environment: Elixir 1.18.5, Erlang/OTP 28. Local verification date: 2026-10-05.

This work package implements the protocol profile in `QuicHttp3.Session` and
the companion codecs. These results establish companion-level behavior;
public Fetch, EventSource, owner/pool scheduling, sustained load and coordinated
artifact acceptance are later work packages.

## Behavior and bounds

Binary request bodies are emitted lazily as HTTP/3 DATA payloads of at most
16,384 bytes. Frame encoding precedes splitting into native admission writes,
so a QUIC write boundary is independent of an HTTP frame boundary. Empty binary
bodies finish the HEADERS write. A body argument of `:stream` keeps the upload
open; `Session.send_data/5` admits caller-demanded chunks of at most 16,384
bytes. `send_data(session, ref, <<>>, true, opts)` sends a real empty native FIN.
Native admission success is not evidence of peer delivery.

The response decoder tracks informational, final, body and trailer phases,
checks status/field/message semantics and content length, and consumes DATA
incrementally. Session events are:

- `{:informational, ref, status, fields}`
- `{:headers, ref, [{":status", status_string} | fields]}`
- `{:data, ref, bytes}`
- `{:trailers, ref, fields}`
- `{:done, ref}`
- `{:stream_error, ref, code, reason}` or
  `{:stream_reset, ref, code, final_size}` for terminal stream failures.

Connection protocol failures return
`{:error, advanced_session, {:http3_error, :connection, code, reason}}`.
Stream semantic failures retire only the affected request and queue RESET/STOP
with the decoder's error code. Terminal FIN/reset removes decoder, runnable and
continuation state exactly once. If a response finishes while its upload is
open, Session resets the sending half and preserves the completed receive
events. It does not STOP an already completed response.

Default local budgets are 128 fields, 65,536 encoded HEADERS bytes, 65,536
decoded field-section bytes, and 262,144 aggregate retained parser bytes.
Decoded accounting includes `name + value + 32` per field. Configuration can
lower the field/header budgets; aggregate retention is configurable up to
1,048,576 bytes. Peer SETTINGS field-section limits also constrain outgoing
requests before stream allocation. Local SETTINGS advertise QPACK capacity
zero, blocked streams zero, and the configured nonzero field-section budget.
Aggregate retention covers response decoders, peer stream prefixes and control
state; it does not count caller-owned binary upload input or delivered events.

Peer unidirectional records are limited to 128, retained continuations to 128,
and generation-aware terminal stream tombstones to 1,024. Admission stops at
the terminal-record limit. Connection rotation before raw QUIC record exhaustion
remains the owner's responsibility. Static-QPACK encoder/decoder streams must
be unique; encoder instructions can only set capacity zero, decoder instructions
must be empty, and critical stream FIN/reset is a connection error. Unknown
unidirectional stream types are discarded incrementally and retire normally.
Unsolicited push is rejected explicitly.

Observed GOAWAY rejects inadmissible stream IDs before opening, and checks the
actual allocated ID afterward. A rejected allocation is RESET/STOP with
H3_REQUEST_REJECTED and is never replayed. Control failures preserve structured
codes, including H3_MISSING_SETTINGS, H3_SETTINGS_ERROR, H3_FRAME_ERROR and
H3_EXCESSIVE_LOAD.

## Continuation and TLS policy contracts

`Session.suspend_blocked/1` detaches only definitely blocked work.
`Session.resume(current_session, continuation)` restores its work onto current
request/decoder/runnable state, uses the original deadline, and consumes the
token once. Cancellation, sending-half reset and response completion invalidate
related tokens. Unknown opens, writes, reads, event drains and resets retain
their operation references and cannot be detached or replayed.
`Session.reset_send/2` abandons definitely blocked upload work and resets only
the sending half while leaving the response readable.

The native adapter retains a supplied compatible TLS wire profile, including
cipher/extension ordering and an explicit SNI position. It validates the profile
before inspection, requires TLS 1.3 and exact `h3` ALPN, and rejects conflicting
cipher/group/signature settings. QUIC transport parameters are generated by the
endpoint rather than replaced with caller bytes. Named profiles and existing
trust/reference-identity verification remain in force.

### Native and fault evidence

The committed native tests use Session plus the actual adapter and native
generation handles over UDP. The peer concatenates the complete request stream
and decodes frame type/length varints without the sender's frame codec. A
42,000-byte arbitrary binary body crosses three DATA frames and many 1,024-byte
native writes. Streamed chunks totaling 24,580 bytes preserve their exact DATA
payloads and terminate via a separate empty native FIN. Both requests receive a
response and leave no active Session request records. Existing native tests
retain response integrity, active cancellation and wrong-reference-name coverage.

The deterministic native-shaped Ops seam exercises fragmented responses,
informational/final/trailers, malformed complete QPACK, HEAD body rejection,
outgoing field budgets, aggregate parser retention, GOAWAY allocation races,
QPACK duplicates/instructions, critical stream closure, extension discard,
continuation expiry/cancellation, and unknown cleanup RESET reconciliation.
An unknown terminal RESET is resolved through its original reference without
reissuing RESET or losing completed response events.

The coordinator independently ran the pinned aioquic 1.2.0 UDP peer. GET and a
61,725-byte POST containing NUL, `1`, CR, LF and `255` passed with authenticated
`h3`, exact echoed DATA integrity, and zero retained request records. The
persistent `scripts/http3/session_gate.py` starts and cleans up its own peer,
requires the pinned peer version, and fails on readiness/body deadlines.

Initial regressions demonstrated the raw-body, response-phase, QPACK/extension,
budget and cleanup defects before implementation. Later regressions reproduced
incorrect control error codes and malformed wire-profile validation raising;
the corresponding scoped fixes now pass.

## Remaining acceptance boundaries

This is static/literal QPACK with Huffman decoding, not dynamic-table QPACK.
0-RTT, migration, Alt-Svc/racing, WebSocket over H3 and WebTransport remain
unsupported. Raw `Quic` capability reporting is unchanged; HTTP/3 semantics
belong to the companion. A connection protocol error is reported with its code;
the caller/owner must close or abort transport resources.

WP2 does not establish public Fetch/SSE acceptance, a second independent server,
32-stream fairness, 10,000-request rotation, a 24-hour canary, release artifact
consumption or publication. Those gates are NOT RUN for this handoff. No commit,
push, tag or release was performed by this worker.
